# 浮窗显示条数与历史回看

设置 → 字幕用一行「显示条数」选择「全部」或「最近 1–10 条」，默认全部。
不另加开关、禁用控件或浮窗按钮。数字表示已确认的字幕句对，不是屏幕
行数；独立输入的实时尾句仍完整保留。说明放在标签旁的帮助提示里。

实时跟随时只投影最近 N 条已确认字幕；主动向上滚动、Home 或 PageUp
进入回看时，展开当前已有的有界历史并保留句子锚点。新句到达不因这个
显示选项移除正在阅读的旧句。点击已有「回到实时」、End 或向下滚到末尾
恢复限制。切换语言显示方式、暂停或修改条数都不擅自结束回看。清空字幕
后重置回看状态。原有全局历史保留上限不变，不新建或复制完整会话历史。

后端 reducer、会话保存、录音和导出均不截断。双源只限制共享顶层确认
列表，各源尾句仍用完整源历史判断身份。投影按历史引用、条数选择和
回看状态缓存，不让健康状态更新反复构建相同字幕列表。

保留 PR 原有持久字段：`custom_subtitle_count_enabled` 与
`visible_subtitle_count`。旧文件缺字段时为 false / 3；保存和加载将数量
钳制到 1..=10。选择数字时在同一个 draft 中启用并设置数量；选择全部
只关闭限制并保留之前数量。会话中可修改，保存失败走既有 toast 和回滚。

Android 不改动：其已有独立的内存历史保留滑杆（0–6，新装默认 3），语义
是保留上限而非显示条数选择，两端差异记入 platform-parity 的
History/recording 行。

验收覆盖默认全部、1/3/10 条、双输入实时尾句、运行中修改、失败回滚、
展开历史的句子锚点、新句到达、回到实时和清空。检查八语言及最小设置
窗口，并在签名开发版确认实际选择与回看行为。运行证据与未覆盖范围记入
`docs/development/integration-runs.md`，不以合成样本声称真实服务或跨设备通过。
