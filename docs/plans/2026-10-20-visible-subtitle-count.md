# 自定义字幕条数

设置 → 字幕新增「自定义字幕条数」开关与「展示条数」下拉（1–10）。开关
默认关闭，关闭时悬浮字幕展示全部已确认字幕，与现行为一致；开启后只
展示最近 N 条已确认字幕，实时尾句照常叠加在最新一条之后。

这是纯显示投影：前端在构建展示块之前对会话历史做最近 N 条切片，后端
reducer 历史、会话历史保存、录制与 TXT 导出都不截断。双源时只限制共享
的顶层历史，各源尾句历史保持完整（仅用于实时块身份判定）。旧偏好文件
缺字段时开关默认关、条数默认 3；存储值在加载与保存时钳制到 1..=10。
属于视觉设置，会话进行中可切换，保存失败走既有 toast。

Android 不改动：其已有独立的内存历史保留滑杆（0–6，新装默认 3），语义
是保留上限而非显示条数选择，两端差异记入 platform-parity 的
History/recording 行。

验证：前端 helper / 设置合并 / 设置页交互的 Vitest 用例，Rust 侧偏好
持久化与草稿通道的单元测试。桌面端到端视觉验收仍需在真实应用中确认
长会话滚动与回看历史行为。
