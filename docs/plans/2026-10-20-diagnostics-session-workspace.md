# 诊断与保存导出工作区

## 目标

让用户能看懂排查线索，并把听过的内容用于回看、整理和后续写作。
用户优先提出“回看整理”和“拿去使用”，本轮将两者串成同一流程。
开发和验证在独立功能分支进行，完成可操作预览后审阅。

## 设计选择

- 诊断保留完整设置子页，先显示当前快照与可执行的下一步，再显示
  声音观测、翻译状态、最新耗时、累计事件；最近事件可展开，原始
  数据默认收起。所有解释只使用已有的安全事实，不推断凭据有效、
  设备选错或字幕渲染正常，不添加健康分数或虚构趋势。
- 保存导出采用“会话列表 → 阅读详情”的本地工作区。保存开关只在
  列表页显示；打开记录后让正文和回听占据主体，返回恢复列表滚动
  与选中项。详情只保留统一导出和更多，重命名、删除／清空归入
  更多；不把低频管理操作与阅读、播放堆成多排同级按钮。
  相比仅调整现有间距，这能改善找到会话和复用内容；相比自动摘要、
  云同步或音视频剪辑，范围仍在 Mimi 已有的本地记录职责内。
- 会话支持命名和按名称搜索、按内容类型过滤，按日期分组展示时间、
  条数和音频。阅读保留现有分页搜索，增加原文／译文／
  双语阅读及单条复制。默认与最小窗口使用原文／译文上下成对阅读，
  避免把约 510 px 的正文区域再切成两条窄列；搜索和阅读方式同行。
  已保存会话导出不受当前实时翻译运行影响。
- 回听使用稳定的内嵌播放器：第一次点击请求有界音频并尝试播放，
  用真实媒体事件更新播放／暂停、时长与可拖动进度，不假造波形或
  未知时长。失败在播放器原位重试。多音源才显示来源选择，保持
  独立音轨；当前内容停止后且仍存在时与已归档录音均可回听。
- 统一导出入口显式选择 TXT、Markdown 或 WAV；文字格式才显示
  原文／译文／双语和是否带时间，音频格式才显示多来源选择，
  然后打开原生保存对话框。音频保持按来源独立导出 WAV。导出目标
  是完整会话，页面搜索不暗中改变范围。
- 暂不增加 SRT/VTT 或点击字幕跳到音频：现有时间是字幕确认时间，
  音频不包含暂停间隔，尚不能提供可靠的音画对齐。

## 边界与数据

- 保存历史与录音仍默认关闭，来源选择及退出时的现有规则保持。
  只在用户操作后复制、导出或播放；播放旧录音前要求停止当前采音，
  避免回放被再次识别。不使用真实历史或凭据作为界面夹具。
- 新增可选会话标题使用独立、有界、私有且原子写入的元数据。
  无标题的既有记录继续显示时间；清空标题恢复该默认。删除记录
  同时清理其元数据，但保持标准确认和既有失败重试。
- 可移植导出格式规则位于 `shared/mimi-runtime`。桌面仅负责读取私有
  文件、原生保存对话框和原子写入，保留活动会话的 revision 校验。
  全文不进入 React 持久状态；阅读仍每页 30 条。
- 诊断补齐前后端错误类别，区分最近错误和当前故障、静音和未观测、
  累计事件和本次会话。双来源采音观测目前是聚合值，不能显示成
  两条独立成功链。只有最新时延，不能生成分布或端到端指标。
- 保留统一 toast、标准确认弹窗、异步串行和迟到结果隔离。
  新文案覆盖全部八种界面语言，使用既有字体、图标与中性色令牌。
- 导出弹窗复用了共享下拉菜单，验证时发现原来的 body portal 被
  弹窗 inert 边界拦截。菜单改为放在所属弹窗内，先处理内层 Esc/Tab，
  再交给弹窗；保持背景隔离。播放器移除前明确暂停并释放媒体资源，
  不把撤销 URL 当成已停止缓冲播放。
- 回听请求始终至多一个在途大文件读取；切换记录、来源、返回列表、
  页面隐藏或开始采音时丢弃旧结果并停止已载入音频。播放器等待
  浏览器实际播放事件，异步读后被 WebKit 拒绝时可再次点击，不将
  “已加载”冒充“已播放”。当前录音读取由桌面生命周期锁保护。

## 实施与验证

1. 安全诊断摘要解析、行动建议与紧凑层级，更新分类／恢复／缺数据
   回归；仅在事实支持时，通过导航回调进入已有的声音或服务页。
2. 添加私有会话标题及共享导出选项，覆盖旧格式兼容、字符边界、
   Markdown 内容安全、不同来源、删除和原子持久化。
3. 重组保存导出页面，加入筛选、阅读、复制、命名、导出选择及重试，
   保留当前记录与已保存记录的身份和生命周期隔离。
4. 扩充统一布局夹具，覆盖真实组件的正常、空、错误、忙碌、恢复、
   长名称、双来源及导出取消；不以加载失败页面充当诊断布局验收。
5. 先在稳定签名 `--watch --ui-only` 应用展示预览，再运行相应快速检查。
   浏览器检查八语言、明暗主题、默认与最小窗口及弹窗；原生确认
   可达性与实际视觉。共享改动运行直接 Rust 和实际 JNI，再进行
   无参数完整检查。平台设备、真实提供商与文件对话框证据分别记录。
6. 独立缺陷复核后收束，不为增加能力而修改识别／翻译调度。记录
   验收限制，清理本轮一次性产物，保留必要证据。

## 浮窗录音提醒预览

用户同意查看轻量预览。复用语言胶囊和收起状态的现有区域，仅在
需要时显示一个静态录音标记，不添加按钮行或计时器，也不复用
表示识别／翻译的动态灯。正常为「录音」，暂停原位变为「录音暂停」，
同时移除重复的普通暂停文案；收起时仅保留带完整可访问标签的标记。
沉浸模式保持现有纯字幕呈现，不增加常驻内容。

后端提供可选 `audioRecording` 状态，旧快照缺省按关闭处理。
实际文件写入成功才提供正常状态，双来源必须都有当前采集尝试的
成功证据；准备、暂停、达到保存上限和写入错误有独立状态。
每源失败保留到会话结束、清空或关闭录音，避免后续成功掩盖缺失。
快照仅读有界内存元数据，状态变化才发布，不逐音频块通知或扫描文件。
录音开关、累计字节或聚合保存错误均不单独视为正常写入证据。
读取写盘统计前释放字幕和生命周期锁；属于某次归档的错误标志须在
归档所有者锁内提交，再在锁外发布，防止迟到回调污染后续会话。
