## English

- Redesigned Android settings and floating captions, with live style previews, adjustable width and height, alignment, timestamps and easier Immersive Mode controls.
- Improved long-caption reading and transitions between original, translated and bilingual subtitles, including screen rotation and brief recognition gaps.
- Added desktop configuration copying and clearer configuration actions, simplified the tray menu and reorganized the usage guide.

Update to v1.5.24 through Mimi's update settings or the installer. Live drafts may still change during recognition. macOS builds are not Apple-notarized.

Contributor: @yuxino.

## 中文

- 重新设计安卓设置和字幕浮窗，支持样式实时预览、宽高调整、对齐、时间显示，沉浸模式操作更方便。
- 改善长字幕阅读，以及原文、译文、双语之间的衔接，修复切屏和识别短暂空档时的显示问题。
- 桌面端增加配置复制，明确配置操作，精简托盘菜单并重新整理使用指南。

可在 Mimi 更新设置中升级至 v1.5.24，或使用安装包。识别过程中的临时字幕仍可能修改。macOS 安装包尚未经过 Apple 公证。
