## English

- Reorganized desktop settings for easier navigation.
- Added Alibaba simultaneous translation on desktop and Android.
- Android supports multiple configurations per service. New installs retain 3 recent captions; existing users keep their settings.
- Improved subtitle stability and reduced translation waits.
- Linux can capture individual playback streams, including separate streams from the same app.
- Windows cleans up old updater installers after upgrading.

Contributors: @EmmetZ, @wangmian0, @yuxino.

## 中文

- 重新整理桌面设置，常用选项更好找。
